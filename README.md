# active-on-current-desktop

适用于 Windows 11 x64 的 Windhawk mod。通过开始菜单搜索或已接入的启动器打开应用时，将其他虚拟桌面的已有主窗口移到当前桌面并激活，保留窗口位置；也可按应用设置例外规则。

当前版本：**1.1.1**。

## 应用程序规则

在 mod 的“设置 → 应用程序规则”中添加应用的 EXE 名称或完整路径，选择打开方式：

| 打开方式 | 行为 |
| --- | --- |
| 未配置的应用（默认） | 将已有窗口移到当前桌面并激活。 |
| 保留所在桌面并跳转 | 激活已有窗口并跳转到其所在桌面，不搬移窗口，适合按桌面整理应用。 |
| 不接管，使用原始启动行为 | 直接执行原始启动请求，适合保留浏览器、资源管理器等应用的多实例行为。是否创建新实例仍由应用决定。 |

名称和路径不区分大小写；空项忽略；重复匹配时“不接管”优先。“保留所在桌面”跟随已有窗口，不绑定固定桌面编号；没有合格的已有窗口时继续原始启动流程。

## 安装与编译

1. 安装 [Windhawk](https://windhawk.net/)，创建本地 mod。
2. 将 [active-on-current-desktop.wh.cpp](active-on-current-desktop.wh.cpp) 的全部源码粘贴到编辑器，保存、编译并启用。无需下载预编译 DLL。
3. 默认已包含 Windows Explorer、搜索和开始菜单进程。第三方启动器可在 mod 的“高级设置 → 自定义包含进程”中添加实际执行启动请求的进程名或路径。
4. 按需配置“应用程序规则”，并停用其他修改相同桌面激活行为的 mod。

“自定义包含进程”用于接入启动器，“应用程序规则”用于配置目标应用，两者独立。即使将资源管理器设为“不接管”，也应保留 Explorer 的默认注入，以处理它发起的其他应用启动请求。

## 说明

- 1.1.x 新增按应用保留所在桌面、原始启动两种规则；1.1.1 精简内部实现，兼容 1.1.0 设置。
- 启动拦截复用普通无参数 EXE / 快捷方式；带参数、特殊动词或特殊快捷方式继续原始启动。同一 EXE 多窗口采用统一选择规则，不识别账号或文档语义。
- 不需要额外常驻程序；不包含行为学习、日志或定时窗口扫描。
- 依赖 Windows 私有 Shell 接口及符号，兼容性取决于系统版本；首次编译或加载时，Windhawk 可能需要联网获取依赖或微软符号。

激活层基于 [Don't Pull Me to Another Desktop](https://github.com/ramensoftware/windhawk-mods/blob/main/mods/prevent-virtual-desktop-stealing.wh.cpp) 改编。完整 MIT 许可及原作者声明见源码。
